# Integrasi Tugas Individu 1–2 dengan Flask

Project ini menggabungkan halaman profil mahasiswa dan daftar nilai ke aplikasi Flask.

## Menjalankan aplikasi (Windows / VS Code)

1. Ekstrak ZIP dan buka folder `Integrasi_Flask_Tugas_Individu_1_2` di VS Code.
2. Buka Terminal di VS Code.
3. (Opsional) Buat virtual environment: `python -m venv venv`
4. Aktifkan: `venv\\Scripts\\activate`
5. Install Flask: `pip install -r requirements.txt`
6. Jalankan: `python app.py`
7. Buka `http://127.0.0.1:5000/`

## Halaman
- `/` : Profil mahasiswa
- `/nilai` : Daftar nilai
- `/admin` : Dashboard admin

Folder `referensi_tugas_1` dan `referensi_tugas_2` menyimpan isi ZIP latihan yang kamu kirim sebagai referensi.
